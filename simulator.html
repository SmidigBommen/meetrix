Parts and how far the simulation goes

    

      
PartSimulatedSimplified or assumed

      
        
Adafruit MatrixPortal S3 (ESP32-S3)GPIO registers on the real pin numbers, one-shot timer interrupt, 1 ms loop, serial, clock sync, boot and resetNot an ESP32 emulator. The C code is compiled for the browser. A real build should use Adafruit's DMA driver for the panel.

        
32×32 RGB panel, HUB75, 1:16 scanSix 32-bit shift registers, latch, row decoder, OE, light added up per LED in nanoseconds20 mA per lit channel, which gives 3.84 A all white. Adafruit states nearly 4 A.

        
Level shifter, 3.3 V to 5 VWith and withoutError rate without it is assumed. Check whether the board already has one; Adafruit's pinout page does not say.

        
Two push buttons, GPIO 6 and 7Contact, bounce, pull-up or floating pin, debounce in firmwareThe board's own keys have no pull-up resistors, so the firmware turns on the internal ones.

        
5 V supplyAverage current from lit LEDs, cable drop, current limit, brownout reset0.1 Ω cable, 4.0 V brownout and controller current are assumed. Measure these first.

        
Wi-Fi and bridge serverJoin, delay, loss, timeout, retry, conflict checkNo TLS, sign-in or device keys yet

        
Microsoft 365calendarView, create, update and delete event with Graph v1.0 paths and status codesNo tokens, time zones, recurrence, paging or throttling
